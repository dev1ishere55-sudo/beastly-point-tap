# Beastly Point Tap

Upgraded wallet-first Solana tap game (Phantom + Solflare).

## Features
- Wallet connect → straight into the game
- Dark/gold gym aesthetic
- Full mining loop (tap, stamina, ranks, upgrades, incubation)
- Supabase-ready cloud save (schema + client included)
- Mobile + desktop

## Files
- `index.html` — complete upgraded game
- `beastly-supabase-client.js` — cloud save client
- `beastly-schema.sql` — database + RLS
- `DEPLOYMENT.md` — Vercel + Supabase steps
